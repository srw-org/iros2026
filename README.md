# IROS 2026

Event site for IROS 2026, part of the [Space Robotics Workshop](https://space-robots.org) series.

Live at **https://space-robots.org/events/iros2026/**

## Local development

```bash
npm install
npm run develop      # http://localhost:8000
```

## What to edit

| File | Contents |
| --- | --- |
| `src/pages/index.tsx` | page content: speakers, agenda, call for papers |
| `src/pages/index.module.scss` | page styles |
| `static/images/` | photos and logos |
